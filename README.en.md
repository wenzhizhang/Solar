# Solar — Solar System Simulator

A real-time 3D solar system simulator built with Three.js — a toy for my daughter, hoping she'll look up at the stars and sail the cosmic ocean!

![Demo](./media/demo.gif)

Live Demo: https://dingfengbo.top/solar/

## Features

- **Realistic Orbital Physics** — Kepler's equation solved via Newton-Raphson iteration, using real astronomical parameters (semi-major axis, eccentricity, orbital period)
- **8 Planets** — Mercury, Venus, Earth, Mars, Jupiter, Saturn (with rings), Uranus, Neptune
- **Earth Details** — day/night textures, cloud layer, shader-based lighting
- **Venus Atmosphere** — translucent atmospheric rendering
- **Moon** — orbiting Earth
- **Asteroid Belt** — 3,000 particles between Mars and Jupiter
- **Sun Glow** — three-layer additive blending glow effect
- **Starry Background** — Milky Way background + star particle field
- **Bilingual (ZH/EN)** — one-click language toggle
- **Interactive Controls** — zoom/rotate/pan, speed slider, pause/resume, reset view
- **Planet Focus** — click a planet label to lock the camera on its orbit
- **Orbit Lines** — elliptical orbit path visualization
