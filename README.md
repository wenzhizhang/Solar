# Solar — 太阳系模拟器

为女儿写的一个基于 Three.js 的实时 3D 太阳系模拟器玩具，希望她能仰望星空，畅游星辰大海！

![Demo](./media/demo.gif)

演示地址：https://dingfengbo.top/solar/

## 特性

- **真实物理轨道** — 基于开普勒方程（牛顿迭代法求解），使用真实天文参数（半长轴、偏心率、公转周期）
- **8 大行星** — 水星、金星、地球、火星、木星、土星（带光环）、天王星、海王星
- **地球细节** — 昼夜纹理、云层、Shader 着色光照
- **金星大气层** — 半透明大气渲染
- **月球** — 绕地公转
- **小行星带** — 火星与木星之间，3000 粒子
- **太阳光晕** — 三层叠加辉光效果
- **星空背景** — 银河背景图 + 星点粒子
- **中英双语** — 一键切换中文/英文界面
- **交互控制** — 缩放/旋转/平移、速度调节、暂停/继续、重置视角
- **行星聚焦** — 点击行星标签跟随视角
- **轨道线** — 显示椭圆轨道路径
